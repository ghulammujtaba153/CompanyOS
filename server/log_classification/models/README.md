# Models

`log_classifier.joblib` — logistic regression head trained on sentence-transformer
embeddings (`all-MiniLM-L6-v2`), sourced from the educational dataset in
https://github.com/codebasics/project-nlp-log-classification

Re-download if missing:

```bash
curl -L -o log_classifier.joblib \
  https://raw.githubusercontent.com/codebasics/project-nlp-log-classification/main/models/log_classifier.joblib
```
